# Activation — DEV-03 : API Designer

## Déclencheurs (Triggers)
1. Nouveau besoin d'API identifié dans le backlog
2. Modification d'un contrat API existant
3. Nouvelle version majeure d'API
4. Intégration avec un service externe nécessitant une API
5. Migration d'API (REST vers GraphQL, etc.)
6. Revue de contrat suite à un incident d'intégration

## Fréquence
- À la demande : conception d'API
- Par sprint : mise à jour des contrats existants
- Par release : revue complète des spécifications

## Prérequis
1. Architecture backend validée par DEV-02
2. Modèle de domaine disponible (DEV-04)
3. Contraintes de sécurité fournies par CORE-05
4. Spécifications fonctionnelles validées par CORE-03

## Désactivation
- Contrat API validé et livré
- Spec refusée → retour en conception
- API dépréciée et retirée
