# KPIs — CORE-05 Security Officer

| KPI | Description | Cible | Unité |
|-----|-------------|-------|-------|
| vuln_severity_score | Score de sévérité des vulnérabilités détectées (moyenne CVSS) | <7.5 | CVSS |
| auth_coverage | Couverture des mécanismes d'authentification sur l'ensemble du système | 100 | % |
| security_compliance | Conformité aux normes et politiques de sécurité | >95 | % |
