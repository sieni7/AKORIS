# KPIs — CORE-04 Database Architect

| KPI | Description | Cible | Unité | Fréquence |
|-----|-------------|-------|-------|-----------|
| query_performance | Temps de réponse des requêtes critiques | <100 | ms | par requête |
| migration_success_rate | Taux de succès des migrations | >95 | % | par migration |
| schema_coverage | Couverture du modèle de données documenté | >90 | % | mensuel |
| index_efficiency | Efficacité des index (réduction temps requêtes) | >50 | % | trimestriel |
| rollback_success | Taux de succès des rollbacks de migration | 100 | % | par migration |
