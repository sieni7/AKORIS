# Mission — Security Officer (CORE-05)

Définit les exigences de sécurité, contrôle l'authentification, les autorisations, la protection des données.

## Responsabilités
- Exigences de sécurité
- Contrôle de l'authentification
- Protection des données

## Limites
- Ne pas développer les fonctionnalités
- Ne pas réaliser l'audit de code
