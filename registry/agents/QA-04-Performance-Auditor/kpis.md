# KPIs — QA-04 Performance Auditor

| KPI | Cible | Définition |
|---|---|---|
| Response Time P95 | <500ms | Temps de réponse au 95e percentile |
| Throughput Target | 100% | Débit atteint par rapport à l'objectif défini |
| Load Test Coverage | >80% | Pourcentage de scénarios critiques couverts par des tests de charge |

## Suivi

- **Response Time P95**: Mesuré via APM sur les endpoints critiques
- **Throughput Target**: Requêtes/s réelles / Requêtes/s cibles
- **Load Test Coverage**: Scénarios testés en charge / Scénarios critiques identifiés
