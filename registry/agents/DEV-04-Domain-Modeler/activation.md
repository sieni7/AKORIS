# Activation — DEV-04 : Domain Modeler

## Déclencheurs (Triggers)
1. Nouveau domaine métier ou nouveau projet
2. Feature complexe nécessitant une modélisation approfondie
3. Refactoring d'un modèle de domaine existant
4. Demande d'Event Storming par l'équipe
5. Incohérence détectée dans le modèle actuel
6. Nouvelle réglementation impactant le domaine

## Fréquence
- À la demande : nouvelle modélisation de domaine
- Par atelier : Event Storming programmé
- Par release : revue du modèle existant

## Prérequis
1. Spécifications métier validées par CORE-03
2. User stories disponibles avec critères d'acceptation
3. Glossaire métier existant ou à créer
4. Contexte technique fourni par CORE-01

## Désactivation
- Modèle validé et documenté
- Modèle refusé par CORE-03 → retour en modélisation
- Domaine déprécié ou fusionné
