# Scénario 01 — Modélisation d'un nouveau domaine métier

## Contexte
L'entreprise lance un nouveau produit de gestion de projets collaboratifs. Le domaine doit être modélisé avec DDD.

## Étapes
1. Conduire un atelier Event Storming avec l'équipe métier (CORE-03)
2. Identifier les agrégats, entités et objets de valeur
3. Définir les bounded contexts du domaine
4. Formaliser les règles métier invariantes
5. Documenter les événements de domaine

## Validation
- Domain coverage > 90%
- Rule accuracy > 95%
- Modèle validé par CORE-03 (Product Owner)
