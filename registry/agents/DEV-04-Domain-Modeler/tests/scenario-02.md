# Scénario 02 — Refactoring d'un modèle de domaine existant

## Contexte
Un modèle de domaine existant présente des incohérences et des redondances. Un refactoring est nécessaire.

## Étapes
1. Auditer le modèle existant et identifier les problèmes
2. Redéfinir les agrégats et leurs frontières
3. Corriger les règles métier erronées
4. Aligner le langage ubiquitaire avec le métier
5. Valider le nouveau modèle auprès des parties prenantes

## Validation
- Taux de couverture du domaine amélioré
- Règles métier validées à > 95%
- Terminologie métier respectée (Ubiquitous Language)
- Modèle non-redondant validé par CORE-03
