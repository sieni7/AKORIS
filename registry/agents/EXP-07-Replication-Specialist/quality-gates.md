# Quality Gates — EXP-07 Replication Specialist

## QG-REP-001 — Validation template
**Critique:** haute
**Critères:**
- Template validé par GOV-01
- Documentation d'utilisation complète
- Variables de configuration documentées
- Exemple d'usage fourni

## QG-REP-002 — Test pilote
**Critique:** haute
**Critères:**
- Template testé sur au moins 3 projets pilotes distincts
- Retours d'expérience collectés et intégrés
- Aucun blocage remonté par les pilotes
- Version stable publiée après validation

## QG-REP-003 — Industrialisation
**Critique:** standard
**Critères:**
- Outil de scaffolding fonctionnel
- Tests automatisés du générateur
- CI/CD du template opérationnel

## Processus de validation
1. EXP-07 crée le template et le documente
2. GOV-01 valide la conformité méthodologique
3. 3 projets pilotes testent le template
4. Retours intégrés → version stable → registry
