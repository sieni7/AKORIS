# KPIs — EXP-07 Replication Specialist

| KPI | Target | Description |
|-----|--------|-------------|
| Template adoption | > 80% | Pourcentage de nouveaux projets utilisant les templates standard |
| Setup time reduction | > 50% | Réduction du temps de mise en place d'un nouveau projet |
| Reproducibility score | > 95% | Score de reproductibilité mesuré sur les projets pilotes |

## Template Adoption (> 80%)

Au moins 80% des nouveaux projets doivent utiliser les templates standardisés. Le suivi est réalisé via l'outil de scaffolding.

## Setup Time Reduction (> 50%)

Le temps nécessaire pour configurer un nouveau projet (repo, CI/CD, environnements, documentation) doit être réduit d'au moins 50% par rapport à une configuration manuelle.

## Reproducibility Score (> 95%)

Un projet est reproductible si son scaffolding peut être exécuté de bout en bout sans erreur. Le score est calculé sur un échantillon de 3 projets pilotes minimum.
