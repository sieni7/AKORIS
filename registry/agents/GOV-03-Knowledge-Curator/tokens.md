# Token Budget — GOV-03 Knowledge Curator

| Category | Value |
|----------|-------|
| Context window | 6 000 tokens |
| Prompt budget | 1 500 tokens |
| Output budget | 1 500 tokens |
| Average usage | 3 000 tokens |
| Maximum usage | 6 000 tokens |

## Guidance

- Prompt doit contenir le contexte de l'incident, les artefacts disponibles et les équipes impliquées.
- Output dédié aux comptes rendus de post-mortem, fiches RETEX et mises à jour de la base de connaissances.
- La capitalisation est prioritaire sur la veille en période de post-incident.
