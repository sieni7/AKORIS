# Scenario 02 — Veille technologique et mise à jour KB

## Contexte

Une nouvelle version majeure de PostgreSQL (17) est publiée. GOV-03 doit évaluer l'impact et mettre à jour la base de connaissances.

## Entrées

- Technologie: PostgreSQL 17
- Version actuelle utilisée: PostgreSQL 16
- Équipes concernées: DEV-02 (Backend), CORE-04 (Database Architect)

## Déroulement attendu

1. GOV-03 analyse les changements de PostgreSQL 17
2. Évalue l'impact sur les projets AKORIS
3. Met à jour les fiches techniques dans la base de connaissances
4. Rédige une note de veille pour les équipes concernées
5. Planifie les actions de migration recommandées
6. Suit l'adoption des recommandations

## Critères de succès

- Note de veille publiée en < 1 semaine
- Base de connaissances mise à jour
- Recommandations de migration documentées
