# GOV-03 — Knowledge Curator

**Domain:** Gouvernance transverse  
**Tags:** `knowledge` `methodology` `documentation`  
**Criticity:** haute  
**Version:** 1.0.0

## Overview

The Knowledge Curator is responsible for knowledge capitalization, maintaining the AKORIS knowledge base, conducting post-mortems, managing lessons learned, and technological watch.

## Key Responsibilities

- Capitalisation des connaissances
- Base de connaissances AKORIS
- Retours d'expérience (RETEX)
- Veille technologique
- Post-mortems

## Dependencies

- GOV-01 (Methodology Guardian)

## Interactions

- GOV-01 — capitalisation des évolutions méthodologiques
- CORE-06 — coordination documentation
- Tous les agents — collecte des retours d'expérience

## Quality Gates

- Knowledge base mise à jour après chaque sprint
