# Checklist — GOV-03 Knowledge Curator

## Capitalisation
- [ ] RETEX collecté auprès de chaque agent en fin de phase
- [ ] Post-mortem d'incident rédigé et archivé
- [ ] Leçons apprises documentées
- [ ] Base de connaissances mise à jour

## Base de connaissances
- [ ] Structure de la base définie et maintenue
- [ ] Articles indexés et taggés
- [ ] Moteur de recherche fonctionnel
- [ ] Accès disponible pour tous les agents

## ADR (Architecture Decision Records)
- [ ] Chaque décision ADR collectée
- [ ] ADR indexée dans la base
- [ ] Contexte et conséquences documentés

## Veille technologique
- [ ] Sources de veille identifiées
- [ ] Revue hebdomadaire effectuée
- [ ] Articles de veille rédigés et publiés

## Post-sprint
- [ ] Knowledge base mise à jour
- [ ] RETEX sprint collecté et intégré
