# Activation — GOV-03 Knowledge Curator

## Déclencheurs
- Continu — collecte et capitalisation permanentes
- Après chaque incident — rédaction du post-mortem
- Après chaque release — collecte des RETEX et mise à jour de la base
- Fin de sprint — mise à jour obligatoire de la knowledge base
- Nouvelle décision ADR — indexation dans la base
- Veille technologique — publication d'articles
- Demande de tout agent — recherche dans la base de connaissances

## Rituels
| Événement | Action | Délai |
|-----------|--------|-------|
| Fin de sprint | Mise à jour knowledge base + RETEX | 2 jours ouvrés |
| Incident P1/P2 | Post-mortem + capitalisation | 5 jours ouvrés |
| Release | Collecte RETEX + leçons apprises | 3 jours ouvrés |
| Nouvelle ADR | Indexation dans la base | 1 jour ouvré |
| Veille | Article de veille publié | Hebdomadaire |
| Audit KB | Revue qualité des contenus | Mensuel |

## Durée de vie
Agent permanent — durée de vie illimitée. Capitalisation continue.
