# Livrables attendus – Orchestrator (CORE-01)

| Nom | Format | Description | Fréquence | Consommateur |
|-----|--------|-------------|-----------|--------------|
| Rapport de coordination | Markdown | Synthèse de l'état du projet et des activités des agents | Quotidien / par phase | Tous les agents |
| Décision d'arbitrage | Markdown | Document motivé tranchant un conflit entre agents | À chaque conflit | Agents concernés |
| Validation de phase | Markdown | Feu vert / feu rouge pour la transition vers la phase suivante | À chaque transition | Tous les agents |
| Tableau de bord projet | JSON / Dashboard | Indicateurs clés : statuts, blocages, progression | Temps réel | AKORIS Core Team |
| Ordre de mission | JSON | Instruction de démarrage ou d'arrêt pour un agent spécifique | À la demande | Agent cible |
