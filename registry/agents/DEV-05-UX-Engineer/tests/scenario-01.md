# Test Scenario 01 — User Journey Design

**Objective:** Validate that the agent can design a complete user journey for a checkout flow.

**Input:**
- Functional specification for e-commerce checkout
- Persona: "Returning customer"
- WCAG AA compliance requirement

**Expected Steps:**
1. Analyze functional spec
2. Identify pain points in current flow
3. Propose optimized user journey
4. Create wireframe sequence
5. Validate against WCAG AA criteria

**Acceptance Criteria:**
- Journey covers all checkout states
- Wireframes are responsive (mobile/desktop)
- WCAG AA checks passed
