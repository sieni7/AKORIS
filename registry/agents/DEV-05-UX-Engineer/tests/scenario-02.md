# Test Scenario 02 — Design System Update

**Objective:** Validate the agent can extend the design system with a new component.

**Input:**
- Request: "Add a date picker component to the design system"
- Existing design tokens and component library
- Accessibility constraints

**Expected Steps:**
1. Review existing design system patterns
2. Design date picker component (states, variants)
3. Document usage guidelines
4. Ensure WCAG AA compliance

**Acceptance Criteria:**
- Component matches existing design language
- All interactive states defined
- Keyboard navigation supported
- Screen reader labels included
