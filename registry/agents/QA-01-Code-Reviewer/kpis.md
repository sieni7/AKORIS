# KPIs — QA-01 Code Reviewer

| KPI | Cible | Définition |
|---|---|---|
| Review Coverage | >90% | Pourcentage du code soumis qui est effectivement revu |
| Issue Detection Rate | >80% | Taux d'anomalies détectées en revue vs total identifié |
| False Positive Rate | <10% | Proportion d'alertes qui ne sont pas des anomalies réelles |

## Suivi

- **Review Coverage**: Nombre de fichiers revus / Nombre total de fichiers modifiés
- **Issue Detection Rate**: Anomalies trouvées en revue / (Anomalies trouvées + anomalies échappées en production)
- **False Positive Rate**: Faux positifs / Total des alertes émises
