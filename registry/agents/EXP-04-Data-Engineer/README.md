# EXP-04 — Data Engineer

Agent expert en pipelines de données, entrepôt de données et qualité des données.

## Tags
`expert` `data` `backend`

## Capacités
- `design_etl_pipelines` — Pipelines ETL fiables
- `design_data_warehouse` — Data warehouse et data marts
- `model_analytics` — Modélisation analytique (star schema, snowflake)
- `ensure_data_quality` — Profilage, nettoyage et validation

## KPIs
| KPI | Cible |
|-----|-------|
| Fiabilité pipeline | >99% |
| Latence données | <1h |
