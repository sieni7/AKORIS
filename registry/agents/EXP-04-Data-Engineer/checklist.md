# Checklist — EXP-04 Data Engineer

## Pipelines ETL
- [ ] Sources de données identifiées et connectées
- [ ] Stratégie d'extraction définie (full / incrémental)
- [ ] Transformations documentées et testées
- [ ] Chargement validé (insert / upsert / merge)
- [ ] Monitoring des pipelines configuré

## Data Warehouse
- [ ] Modèle dimensionnel conçu (faits / dimensions)
- [ ] Schéma choisi (star / snowflake / vault)
- [ ] Partitions et indexes optimisés
- [ ] Stratégie de rafraîchissement définie

## Qualité des données
- [ ] Règles de validation définies
- [ ] Profiling des sources effectué
- [ ] Nettoyage et déduplication appliqués
- [ ] Alertes de qualité configurées

## Data Governance
- [ ] Lignage des données documenté
- [ ] Catalogue de données mis à jour
- [ ] Accès et sécurité définis avec CORE-05
- [ ] Rétention et archivage planifiés
