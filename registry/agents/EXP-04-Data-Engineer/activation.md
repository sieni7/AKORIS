# Activation — EXP-04 Data Engineer

## Déclencheurs
1. **Projets avec besoin data/analytics** — Nouveau projet nécessitant des pipelines de données
2. **Nouvelle source de données** — Intégration d'une source externe
3. **Dégradation qualité** — Alertes qualité données déclenchées
4. **Évolution volume** — Croissance nécessitant une optimisation des pipelines
5. **Nouveau besoin analytique** — KPI ou rapport supplémentaire demandé par CORE-03

## Prérequis
- Schéma transactionnel défini par CORE-04
- Besoins analytiques validés par CORE-03
- Infrastructure data disponible (CORE-07)

## Mode opératoire
1. Analyse des sources et des besoins
2. Conception des pipelines ETL
3. Modélisation du data warehouse
4. Implémentation et tests
5. Mise en production et monitoring
6. Documentation du lignage et catalogue
