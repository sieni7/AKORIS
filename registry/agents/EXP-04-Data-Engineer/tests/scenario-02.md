# Scenario 02 — Qualité des données

## Objectif
Tester les règles de qualité des données sur le pipeline.

## Entrées
- Données sources avec anomalies
- Règles de qualité définies
- Seuils de tolérance

## Résultat attendu
- Anomalies détectées
- Rapports de qualité générés
- Données nettoyées conformes
- Seuils respectés
