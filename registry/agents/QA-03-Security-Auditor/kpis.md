# KPIs — QA-03 Security Auditor

| KPI | Cible | Définition |
|---|---|---|
| Vuln Critical Count | 0 | Nombre de vulnérabilités critiques en production |
| Vuln High Count | <5 | Nombre de vulnérabilités haute sévérité ouvertes |
| Audit Frequency | Monthly | Fréquence minimale des audits de sécurité |

## Suivi

- **Vuln Critical Count**: 0 tolérance pour les vulnérabilités critiques
- **Vuln High Count**: Nombre de vulnérabilités CVSS ≥ 7.0 non corrigées
- **Audit Frequency**: Audit complet au moins 1 fois par mois
