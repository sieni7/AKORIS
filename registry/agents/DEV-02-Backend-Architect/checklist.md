# Checklist — Backend Architect

## Architecture
- [ ] Architecture globale définie (monolithe / microservices / serverless)
- [ ] Découpage en services validé
- [ ] Diagramme de déploiement produit
- [ ] Patterns d'intégration choisis

## Services
- [ ] Périmètre de chaque service défini
- [ ] Interfaces entre services documentées
- [ ] Middleware identifiés et configurés
- [ ] Stratégie de communication inter-services (sync/async)

## Performance
- [ ] Temps de réponse cible défini (p50, p95, p99)
- [ ] Stratégie de caching définie
- [ ] Scalabilité horizontale/verticale évaluée
- [ ] Throughput cible validé

## Standards
- [ ] Stack technique choisie et validée
- [ ] Règles de linting backend configurées
- [ ] Conventions de nommage établies
- [ ] Documentation d'architecture à jour

## Tests
- [ ] Tests d'intégration planifiés par service
- [ ] Tests de charge prévus
- [ ] Stratégie de mocking définie
- [ ] CI/CD intégré avec tests automatisés
