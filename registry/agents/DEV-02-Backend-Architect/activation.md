# Activation — DEV-02 : Backend Architect

## Déclencheurs (Triggers)
1. Nouvelle fonctionnalité backend identifiée dans le backlog
2. Création d'un nouveau service ou module
3. Refactoring d'un service existant
4. Migration vers une nouvelle stack ou architecture
5. Alerte de performance backend (temps de réponse excessif)
6. Nouveau projet ou nouveau domaine métier

## Fréquence
- À la demande : conception de service
- Par sprint : revue d'architecture backend
- Par release : audit de performance et scalabilité

## Prérequis
1. Spécifications fonctionnelles validées par CORE-03
2. Règles métier fournies par DEV-04
3. Contraintes techniques et architecture globale de CORE-01
4. Modèle de données disponible (au moins draft de CORE-04)

## Désactivation
- Service livré et validé par QA
- Architecture refusée → retour en conception
- Plus de service backend dans le périmètre
