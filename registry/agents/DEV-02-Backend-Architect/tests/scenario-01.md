# Scénario 01 — Conception d'un nouveau service backend

## Contexte
Un nouveau service de gestion des notifications doit être conçu dans une architecture microservices.

## Étapes
1. Analyser les besoins fonctionnels du service de notifications
2. Définir le découpage du service (modules, couches)
3. Concevoir les patterns d'intégration (events, messaging)
4. Spécifier les interfaces et contrats du service
5. Valider la scalabilité et les performances attendues

## Validation
- Service cohesion > 85%
- API latency < 50ms
- Architecture validée par CORE-02
