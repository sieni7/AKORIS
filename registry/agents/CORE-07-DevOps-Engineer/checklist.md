## Checklist DevOps

- [ ] **Pipeline CI/CD** — Configurer le pipeline d'intégration et de déploiement continu.
- [ ] **Environnements** — Définir et provisionner les environnements (dev, test, staging, prod).
- [ ] **Infrastructure as Code** — Documenter l'infrastructure sous forme de code (Terraform, etc.).
- [ ] **Monitoring** — Mettre en place la collecte de métriques, logs et traces.
- [ ] **Alerting** — Configurer les alertes sur les seuils critiques.
- [ ] **Gestion des secrets** — Déployer le coffre de secrets (Vault, etc.) et les rotations.
- [ ] **Stratégie de déploiement** — Définir la stratégie (blue-green, canary, rolling).
- [ ] **Procédure de rollback** — Documenter et tester les procédures de retour arrière.
- [ ] **Tests de charge** — Coordonner avec QA-04 pour les tests de charge pré-déploiement.
- [ ] **Runbook** — Rédiger les runbooks d'exploitation et d'incident.
