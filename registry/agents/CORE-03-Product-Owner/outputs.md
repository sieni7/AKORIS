# Livrables attendus – Product Owner (CORE-03)

| Nom | Format | Description | Fréquence | Consommateur |
|-----|--------|-------------|-----------|--------------|
| Backlog priorisé | Markdown / JSON | Liste ordonnancée des user stories par valeur métier | Continu / chaque sprint | Tous les agents |
| User stories | Markdown | Stories avec description et critères d'acceptation | Chaque sprint | DEV-01..08, QA-01..07 |
| Critères d'acceptation | Markdown | Définition de "fait" pour chaque fonctionnalité | Par story | DEV, QA |
| Rapport de sprint review | Markdown | Bilan du sprint : livré, non livré, écarts, décisions | Fin de sprint | CORE-01, parties prenantes |
| Validation fonctionnelle | Markdown | Résultat de la validation : accepté / refusé + motifs | Par livrable | DEV concerné, CORE-01 |
| Roadmap produit | Markdown | Vision macro des prochaines livraisons | Mensuel / trimestriel | Parties prenantes, CORE-01 |
