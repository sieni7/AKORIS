# KPIs — DEV-01 Frontend Architect

| KPI | Cible | Mesure |
|-----|-------|--------|
| Lighthouse Score | > 90 | Performance, SEO, Accessibility |
| Component Reuse | > 70% | Ratio composants réutilisés / total |
| Bundle Size | < 200 KB | Taille du bundle JS à l'arrivée |

## Notes
- Lighthouse Score mesuré via audits QA-04
- Component Reuse évalué par analyse statique du code
- Bundle Size vérifié à chaque build via webpack/rollup analyzer
