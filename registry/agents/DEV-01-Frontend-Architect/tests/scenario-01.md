# Scénario 01 — Conception d'une nouvelle feature UI

## Contexte
L'équipe produit souhaite ajouter un nouveau tableau de bord utilisateur avec des widgets personnalisables.

## Étapes
1. Analyser les maquettes UI fournies par DEV-05
2. Concevoir l'arbre de composants React pour le tableau de bord
3. Définir le state management (store, reducers, actions)
4. Proposer une stratégie de lazy loading pour les widgets
5. Estimer l'impact sur le bundle size

## Validation
- Arbre de composants validé par CORE-02
- Bundle size < 200 KB
- Lighthouse score > 90
