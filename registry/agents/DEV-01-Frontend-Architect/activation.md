# Activation — DEV-01 : Frontend Architect

## Déclencheurs (Triggers)
1. Nouvelle feature UI identifiée dans le backlog
2. Mise à jour du design system ou des tokens
3. Refactoring de composants existants
4. Migration de framework ou de librairie majeure
5. Alerte de performance (Lighthouse < 80)
6. Nouveau projet ou nouveau module frontend

## Fréquence
- À la demande : conception de feature
- Par sprint : revue d'architecture
- Par release : audit de performance et accessibilité

## Prérequis
1. Spécifications UI/UX validées par DEV-05
2. Contrats API disponibles (au moins draft)
3. Design system tokens accessibles
4. Contexte technique fourni par CORE-01

## Désactivation
- Feature livrée et validée par QA
- Architecture refusée → retour en conception
- Plus de feature frontend dans le périmètre
