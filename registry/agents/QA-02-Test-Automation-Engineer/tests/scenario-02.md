# Scenario 02 — Tests E2E sur parcours critique

## Objectif
Vérifier que QA-02 génère des tests E2E pour un parcours utilisateur complet.

## Entrées
- Parcours: "Création de compte → Connexion → Commande → Paiement"
- API contracts
- Spécifications UI

## Étapes
1. Soumettre le parcours et les contrats à QA-02
2. QA-02 analyse le flux
3. QA-02 génère les tests E2E

## Résultat attendu
- Tests E2E couvrant le parcours complet
- Assertions sur chaque étape clé
- Rapport de couverture E2E généré
