# KPIs — QA-02 Test Automation Engineer

| KPI | Cible | Définition |
|---|---|---|
| Test Coverage | >80% | Pourcentage de code couvert par des tests automatisés |
| Automation Rate | >90% | Proportion de tests exécutés automatiquement vs manuellement |
| Test Reliability | >95% | Taux de tests passant de façon fiable (non flaky) |

## Suivi

- **Test Coverage**: Lignes de code couvertes / Total lignes de code
- **Automation Rate**: Tests automatisés / (Tests automatisés + tests manuels)
- **Test Reliability**: Tests réussis sans flakiness / Total d'exécutions de tests
