# Activation — EXP-03 Mobile Specialist

## Déclencheurs
1. **Projets avec composante mobile** — Nouveau projet mobile ou ajout mobile à un projet existant
2. **Mise à jour plateforme** — Nouvelle version iOS/Android impactant l'architecture
3. **Problème de performance** — Dégradation constatée sur device
4. **Soumission store** — Préparation de build pour soumission App Store ou Play Store

## Prérequis
- API backend définie par DEV-02
- Design UX/UI validé par DEV-05
- Architecture globale validée par CORE-02

## Mode opératoire
1. Analyse des spécifications mobiles
2. Choix du framework et de l'architecture
3. Conception de la synchronisation offline
4. Implémentation des features natives et push
5. Tests sur device réel
6. Préparation et validation store
