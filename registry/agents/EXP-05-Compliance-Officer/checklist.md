# Checklist — EXP-05 Compliance Officer

## RGPD
- [ ] Registre des traitements à jour
- [ ] Consentements utilisateurs documentés
- [ ] Délégation de protection des données désignée
- [ ] Durée de conservation définie par traitement
- [ ] Analyse d'impact (DPIA) réalisée pour les traitements à risque

## ISO
- [ ] Périmètre de certification défini
- [ ] Documentations obligatoires à jour
- [ ] Revues de direction planifiées
- [ ] Audits internes réalisés
- [ ] Actions correctives suivies

## Sectoriel
- [ ] Exigences sectorielles identifiées
- [ ] Écart analysé
- [ ] Plan de mise en conformité établi

## Pré-mise en production
- [ ] Conformité RGPD vérifiée
- [ ] DPIA signée si nécessaire
- [ ] Registre mis à jour
- [ ] Rapport d'audit transmis à GOV-01
