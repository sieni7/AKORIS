# Token Budget — EXP-06 Ops Specialist

| Category | Value |
|----------|-------|
| Context window | 6 000 tokens |
| Prompt budget | 1 500 tokens |
| Output budget | 1 500 tokens |
| Average usage | 3 000 tokens |
| Maximum usage | 6 000 tokens |

## Guidance

- Prompt doit contenir le contexte d'incident, l'état des dashboards et les runbooks applicables.
- Output limité aux actions correctives immédiates et aux mises à jour de statut.
- En cas d'incident complexe, plusieurs itérations peuvent être nécessaires dans la limite du budget total.
