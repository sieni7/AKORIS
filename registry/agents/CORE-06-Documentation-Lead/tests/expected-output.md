# Expected Deliverables — CORE-06 Documentation Lead

## Format des livrables

| Livrable | Format | Contenu minimal | Destinataire |
|----------|--------|-----------------|--------------|
| Structure documentaire | Markdown (`.md`) | Arborescence, conventions, gabarits, index | Tous |
| ADR indexés | Markdown (`.md`) | Décision, contexte, options, conséquences, statut | CORE-01, CORE-02 |
| Base de connaissances | Markdown / Wiki | Articles, glossaire, FAQ, liens | Tous |
| Guides d'utilisation | Markdown (`.md`) | Procédures, exemples, captures d'écran | Tous |
| Rapport de couverture documentaire | Markdown (`.md`) | Statistiques, lacunes, plan d'action | CORE-01 |

## Règles de qualité
- Chaque document doit suivre le template défini dans la structure documentaire.
- Les ADR doivent être approuvés par CORE-01 avant publication.
- Les liens internes doivent être validés automatiquement.
- Le rapport de couverture est produit avant chaque release.
