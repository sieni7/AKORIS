# Quality Gates — CORE-06 Documentation Lead

| ID | Nom | Description | Critères | Sévérité |
|----|-----|-------------|----------|----------|
| QG-CORE-06-01 | Documentation complète | Vérification que tous les domaines sont documentés avant release | Chaque agent a fourni sa documentation, structure respectée | Bloquant |
| QG-CORE-06-02 | ADR à jour | Contrôle que toutes les décisions architecturales ont un ADR | Tout ADR a un statut (proposé, accepté, déprécié), indexé | Critique |
| QG-CORE-06-03 | Liens valides | Vérification des liens internes de la documentation | Aucun lien brisé dans la base documentaire | Majeur |
| QG-CORE-06-04 | Qualité rédactionnelle | Revue de la clarté et de la cohérence des documents | Langage clair, sections bien structurées, pas de fautes critiques | Mineur |
| QG-CORE-06-05 | Base connaissances à jour | Vérification de la currency de la base de connaissances | Informations clés du projet mises à jour (contexte, décisions) | Majeur |
