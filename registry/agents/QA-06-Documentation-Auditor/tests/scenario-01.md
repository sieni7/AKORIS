# Scenario 01: Audit documentation complet

**Objectif:** Vérifier l'exhaustivité de la documentation pour un module livré.

## Préconditions
- Module "User Management" livré avec documentation associée
- Modèle de documentation AKORIS disponible
- Style guide AKORIS disponible

## Déroulement
1. Activer QA-06 avec `akoris activate QA-06`
2. Fournir le chemin du module et sa documentation
3. Lancer l'audit d'exhaustivité
4. Vérifier la conformité au style guide

## Résultats attendus
- Rapport d'audit structuré
- Score de complétude par document
- Liste des documents manquants
- Écarts de conformité au style guide

## Critères de succès
- Score de complétude > 90%
- Conformité au style guide > 95%
- Aucun document orphelin
