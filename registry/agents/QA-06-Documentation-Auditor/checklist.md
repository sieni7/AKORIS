# Checklist — Documentation Audit

| id | catégorie | vérification | obligatoire |
|----|-----------|-------------|-------------|
| DA-01 | Présence | README présent et à jour ? | oui |
| DA-02 | Présence | Documentation technique du module présente ? | oui |
| DA-03 | Présence | ADR (Architecture Decision Records) présents ? | oui |
| DA-04 | Présence | Guide d'installation / déploiement présent ? | oui |
| DA-05 | Présence | CHANGELOG tenu à jour ? | non |
| DA-06 | Cohérence | Terminologie cohérente entre les documents ? | oui |
| DA-07 | Cohérence | Références croisées valides (pas de liens morts) ? | oui |
| DA-08 | Cohérence | Version du produit cohérente dans tous les docs ? | oui |
| DA-09 | Qualité | Documentation rédigée en français ou anglais (selon projet) ? | oui |
| DA-10 | Qualité | Structure respectée (titres, tableaux, listes) ? | oui |
| DA-11 | Qualité | Exemples de code fonctionnels et à jour ? | non |
| DA-12 | Complétude | Toutes les fonctionnalités du module documentées ? | oui |
| DA-13 | Complétude | Cas d'erreur et edge cases documentés ? | non |
| DA-14 | Complétude | Guide de contribution présent ? | non |
| DA-15 | Conformité | Respect du style guide AKORIS ? | oui |
