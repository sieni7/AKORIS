# Politique : Zéro code spaghetti

**ID** : `policy-zero-spaghetti`
**Version** : 1.0.0

## Règle

L'architecture, la séparation des responsabilités, la lisibilité et la cohérence du code sont contrôlées en continu.

## Application

- Respect des principes SOLID
- Séparation claire des couches (présentation, métier, données)
- Pas de duplication de code
- Nommage explicite et cohérent
- Tests associés à toute logique métier

## Sanction

Une violation entraîne un blocage du Quality Gate **Architecture**.
