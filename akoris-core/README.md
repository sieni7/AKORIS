# AKORIS Core

Référentiel central de la méthode de gouvernance AKORIS.

## Structure

```
constitution/       → Constitution AKORIS (règles immuables)
registry/
  agents/           → Définitions des agents
  policies/         → Politiques de qualité et sécurité
  quality-gates/    → Seuils et critères de validation
  checklists/       → Listes de vérification
  templates/        → Gabarits de documents
  metrics/          → Définitions des métriques
  workflows/        → Modèles de cycle
  knowledge/        → Capitalisation (leçons, pratiques)
rolebook/
  core/             → 8 agents Core
  experts/          → 25 agents Expert
schemas/            → Schémas JSON de validation
```

**Version courante** : 2.0.0
