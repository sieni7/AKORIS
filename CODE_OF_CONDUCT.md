# Code de conduite — AKORIS

## Notre engagement

AKORIS est un projet de gouvernance ouvert. Nous nous engageons à offrir une expérience de participation respectueuse, bienveillante et inclusive pour tous.

## Normes attendues

- Respect mutuel
- Communication constructive
- Écoute active
- Bienveillance et empathie
- Reconnaissance des contributions
- Professionnalisme

## Comportements inacceptables

- Harcèlement, intimidation ou discrimination
- Insultes, attaques personnelles ou langage dégradant
- Trolling ou provocation
- Divulgation non autorisée d'informations confidentielles
- Toute forme de violence ou de menace

## Signalement

Pour signaler un comportement inacceptable, contactez le mainteneur :

- **Email** : sieni7@gmail.com
- **GitHub** : [sieni7](https://github.com/sieni7)

Tout signalement sera traité avec confidentialité et impartialité.

## Application

Le mainteneur du projet a le droit de prendre toute mesure jugée appropriée, incluant l'avertissement, la suspension temporaire ou l'exclusion définitive de tout contributeur dont le comportement est jugé inacceptable.
