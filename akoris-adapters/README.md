# AKORIS Adapters

Traduction des rôles et contrats AKORIS vers les formats spécifiques de chaque moteur IA.

## Structure

```
opencode/       → Contrats AKORIS → OpenCode agents
cursor/         → Contrats AKORIS → Cursor rules
claude-code/    → Contrats AKORIS → Claude Code prompts
codex/          → Contrats AKORIS → Codex prompts
copilot/        → Contrats AKORIS → GitHub Copilot
```

Chaque adaptateur permet à un moteur IA d'exécuter les contrats AKORIS sans modification de la méthode.
