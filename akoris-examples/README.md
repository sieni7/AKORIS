# AKORIS Examples

Projets de référence démontrant l'application de la méthode AKORIS sur différentes stacks.

## Exemples prévus

- `react-supabase/` — Application React + Supabase + Netlify
- `nextjs/` — Application Next.js
- `laravel/` — API Laravel
- `flutter/` — Application mobile Flutter

Chaque exemple est un projet complet avec `.akoris/` déployé à la racine.
