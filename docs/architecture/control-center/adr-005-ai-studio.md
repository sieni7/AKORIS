# ADR-005 : AI Studio

**Contexte** : L'IA est un outil puissant, mais les prompts sont souvent génériques et manquent de contexte projet.

**Décision** : Développer un module AI Studio dans le Dashboard pour construire, tester et sauvegarder des prompts contextualisés.

**Alternatives** : Utiliser des outils externes (LangChain, PromptLayer) ou rester sur le CLI.

**Justification** : L'AI Studio est le différenciateur d'AKORIS. Il combine la gouvernance (Registry, ADR) avec la génération de prompts, ce qui n'existe dans aucun autre outil.

**Statut** : Accepté.
