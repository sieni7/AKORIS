# Script vidéo — Présentation AKORIS (~3 min)

> Format : screencast + voix off. Chaque bloc correspond à une séquence visuelle.

---

## 1. Accroche

Quand une IA génère du code, elle va vite. Mais la vitesse sans gouvernance, c'est de la dette technique qui s'accumule à chaque commit. AKORIS change cette dynamique.

**[Visuel : code qui défile, puis ralenti]**

---

## 2. Le problème

Vous avez constaté le même phénomène ? Les décisions d'architecture disparaissent entre deux sessions. Le schéma de base de données change sans justification. L'IA invente des conventions qui n'existent pas. Et personne ne sait pourquoi le code ressemble à ça.

Le problème n'est pas l'IA — c'est l'absence de cadre.

**[Visuel : chaîne de commits incohérents, puis arrêt brutal]**

---

## 3. La solution — trois mécanismes

AKORIS introduit trois mécanismes simples.

Premièrement, des **contrats** : chaque agent — humain ou IA — a une mission claire, des responsabilités définies et des limites explicites.

Deuxièmement, des **règles** : des Quality Gates vérifient chaque étape du cycle de vie, et un Decision Gate garantit que l'humain décide toujours en fin de chaîne.

Troisièmement, une **machine à états** : le projet suit un cycle de huit états nominaux, de Proposition à Archivé, avec trois états exceptionnels pour gérer les imprévus.

**[Visuel : diagramme animé — cycle de vie complet]**

---

## 4. Les fondations

AKORIS repose sur quatre principes : la gouvernance d'abord, la documentation avant l'implémentation, l'auditabilité conçue dès le départ, et l'architecture définie avant toute ligne de code.

Chaque principe garantit que la méthode s'applique avant que le premier prompt ne soit écrit.

**[Visuel : hiérarchie normative animée]**

---

## 5. Profils

AKORIS s'adapte à votre niveau de risque — d'un profil Lite pour les prototypes jusqu'à un profil Critical pour les projets sensibles — sans alourdir votre processus.
