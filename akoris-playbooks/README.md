# AKORIS Playbooks

Guides d'application adaptés à chaque stack technologique ou type de projet.

## Structure

```
react-supabase/     → Playbook React + Supabase + Netlify
nextjs/             → Playbook Next.js
laravel/            → Playbook Laravel
flutter/            → Playbook Flutter
spring-boot/        → Playbook Spring Boot
dotnet/             → Playbook .NET
```

Chaque playbook est un module indépendant, installable via `akoris install playbook <name>`.
